# TRAIP AI : RE HTML Presentation

이 디렉터리의 HTML 파일을 로컬에서 직접 열어 사용합니다. 별도 서버, 빌드, 동기화 과정은
필요하지 않습니다.

## 조작

- `←`, `↑`, `PageUp`, `Backspace`: 이전 슬라이드
- `→`, `↓`, `PageDown`, `Space`: 다음 슬라이드
- `Home`, `End`: 첫 장 / 마지막 장
- `M`: 목차 열기 / 닫기
- `Esc`: 목차 닫기
- 화면 좌우 스와이프: 모바일 슬라이드 이동

기본 발표본은 `index.html`입니다.

## 프로젝트 개요·AX 강조 발표본

기존 발표본을 보존한 새 발표본은 아래 파일을 직접 열어 사용합니다.

```text
2차/index.html
```

이 발표본은 외부 서비스나 별도 로컬 서버 없이 동작합니다. 모바일 경험 페이지도 실제 WebApp을
불러오지 않고, 발표 흐름에 맞춘 고정 대화 애니메이션을 로컬에서 재생합니다.
