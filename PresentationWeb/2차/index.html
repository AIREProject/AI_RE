APPENDIX · GENERATIVE AI

아이디어를 빠르게 형태로 옮기는
우리의 제작 도구

생성형 AI를 결과를 대신 만드는 도구가 아니라,
탐색과 시안, 구현을 빠르게 연결하는 제작 파트너로 활용했습니다.

01 PLAYER MODEL 플레이어 모델

레퍼런스 탐색과 콘셉트 방향을 빠르게 비교하며 캐릭터의 첫 인상을 구체화했습니다.

02 UI / UX UI 설계

플레이 흐름에 맞는 화면 구성과 문구를 여러 시안으로 검토해, 더 자연스러운 경험을 다듬었습니다.

03 VISUAL ASSET 이미지 제작

월드와 캐릭터의 분위기를 전달할 이미지 초안을 만들고, 발표와 프로토타입의 톤을 맞췄습니다.

04 CODE / BACKEND 구현 가속

게임 로직부터 UI, 백엔드 구조와 API 검증 흐름까지 구현의 출발점과 점검을 보조했습니다.

사람의 판단으로 방향을 정하고, 생성형 AI로 반복의 속도를 높였습니다.
