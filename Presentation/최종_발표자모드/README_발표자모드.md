# AI : RE 웹 발표자 모드

원본 `최종` 폴더와 분리된 발표용 사본입니다. 이 폴더의 웹 파일만 발표자 모드에 맞게 변경되었습니다.

## 권장 실행: PowerPoint 방식 자동 화면 전환

`발표_시작.cmd`를 더블클릭합니다.

1. Windows 화면이 복제에서 확장 모드로 바뀝니다.
2. 로컬 서버와 Chrome 또는 Edge 발표자 화면이 자동으로 열립니다.
3. 웹 발표자 화면에서 `청중 화면 열기`를 누릅니다.
4. 두 번째 모니터의 청중 창에서 `전체화면 시작`을 누릅니다.
5. 발표가 끝나면 시작할 때 열린 명령 창에서 Enter를 누릅니다.
6. 서버가 종료되고 Windows 화면이 복제 모드로 복구됩니다.

명령 창을 실수로 닫았거나 복제 모드로 돌아오지 않았다면 `발표_종료.cmd`를 더블클릭합니다.

> Windows의 진짜 복제 모드에서는 두 출력에 서로 다른 화면을 표시할 수 없습니다. 이 실행기는 PowerPoint Presenter View처럼 발표 중에만 확장 모드로 전환하고 종료 후 복제로 되돌립니다.

## 수동 실행

1. PowerShell 또는 명령 프롬프트에서 이 폴더로 이동합니다.
2. 아래 명령으로 로컬 서버를 실행합니다.

   ```powershell
   node server.mjs
   ```

3. Chrome 또는 Edge에서 다음 주소를 엽니다.

   ```text
   http://127.0.0.1:4173/?presenter=1
   ```

4. Windows 디스플레이를 확장 모드로 변경합니다.
5. `청중 화면 열기`를 누르고 다중 화면 관리 권한을 허용합니다.
6. 두 번째 모니터에 열린 청중 창에서 `전체화면 시작`을 한 번 누릅니다.
7. 발표자 화면으로 돌아와 타이머를 시작합니다.

다중 화면 권한을 거부했거나 자동 배치가 되지 않으면 청중 창을 두 번째 모니터로 직접 옮긴 뒤 `전체화면 시작` 또는 `F11`을 사용합니다.

## 발표자 조작

- `←`, `↑`, `PageUp`, `Backspace`: 이전 슬라이드
- `→`, `↓`, `PageDown`, `Space`: 다음 슬라이드
- 영상 슬라이드에서 `Space`: 영상 재생 또는 일시정지
- `Home`, `End`: 첫 장 / 본문 마지막 장
- `M`: 목차 열기 / 닫기
- `T`: 전체·슬라이드 타이머 시작 / 일시정지
- `Shift+R`: 전체·슬라이드 타이머 초기화

일반 슬라이드 화면에서는 우측 상단 `발표자 모드` 버튼 또는 `P` 키로 발표자 모드에 들어갈 수 있습니다.

## 대본 수정

`대본.md`가 발표자 노트의 단일 원본입니다.

```markdown
## 1. 표지 — 0:35

발표 대본...
```

- `## 번호. 제목 — 분:초` 형식을 유지합니다.
- 본문 슬라이드는 1번부터 11번까지 순서대로 작성합니다.
- 대본을 수정한 뒤 발표자 페이지를 새로고침하면 반영됩니다.
- 부록 슬라이드는 대본이 없는 상태로 표시됩니다.

## 영상과 소리

- 발표자 창의 영상이 소리의 기준입니다.
- 청중 창의 영상은 발표자 영상과 위치를 맞추되 음소거됩니다.
- Windows 기본 오디오 출력 장치를 발표 장소의 스피커 또는 HDMI 출력으로 설정합니다.

## 발표 전 점검

- Chrome/Edge 팝업과 다중 화면 관리 권한이 허용되어 있는지 확인합니다.
- 발표자 화면과 청중 화면의 슬라이드 이동이 일치하는지 확인합니다.
- 영상의 재생, 일시정지, 탐색과 오디오 출력을 확인합니다.
- `대본.md` 경고가 없는지 확인합니다.
- 발표 시작 전 타이머가 `00:00`인지 확인합니다.
