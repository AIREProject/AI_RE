# Legacy JSON Schemas

이 디렉터리의 schema는 2026-07-27 이전 Backend 계약용 참고 자료입니다. 현재 배포
`https://traip.mtvs2026.work/openapi.json` 또는 `AIRE_SERVER/app/`의 FastAPI model과 일치한다고
가정하지 않습니다.

현재 client 생성, runtime 지원 판정과 validator 구현에는 이 schema를 사용하지 않습니다.
정확한 권위와 정합성 확인 절차는 [`../README.md`](../README.md)를 따릅니다.
